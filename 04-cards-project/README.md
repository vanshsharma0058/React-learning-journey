# 🚀 React Job Opening Card Project

This project is a simple **React application** that displays a list of job opening cards.  
Each card includes a **company logo, name, role, job type tags, payment rate, and location**.  
It’s perfect for beginners learning React components and props.

---

## 🎯 What You’ll Learn

- How to create and use **functional components** in React
- How to **pass data using props** between components
- How to **map through an array** of data to render multiple cards
- How to add **basic styling** using CSS or Tailwind CSS

---

## 🧩 Project Preview

Each job card displays:

- Company Logo
- Company Name
- Job Role
- Tags (e.g., Full-time, Junior-level)
- Pay Rate (e.g., $120/hr)
- Location

Example:

| ![Google Logo](https://logo.clearbit.com/google.com) | **Google** — Frontend Developer | 💼 Full-time | 🧑‍💻 Junior-level | 💰 $80/hr | 📍 Bangalore, India |

---

## ⚙️ Prerequisites

- Basic understanding of **React** and **JavaScript**
- **Node.js** and **npm** installed
- A **code editor** like Visual Studio Code (VS Code)

---

## 🛠️ How to Run the Project

```bash
# 1. Create a new React app
npm create vite@latest react-job-card --template react

# 2. Move into the project folder
cd react-job-card

# 3. Install dependencies
npm install

# 4. Run the app
npm run dev
```
